# Lv.1 零基础贡献者

**你不需要懂任何编程**，也能为项目做出实实在在的贡献。这一页列出几件只要你会玩游戏、会用浏览器就能做的事。

## 你能做的事

### 1. 反馈 bug 与异常

这是最有价值的贡献之一。开发者无法在所有设备上测试，**你的设备就是一个独特的测试环境**。

- 遇到闪退、卡顿、显示错误 → 按 [反馈指南](/player/feedback) 提一个清晰的 Issue；
- 带上 **设备型号、系统版本、客户端版本、复现步骤、截图/录屏**；
- 这就够了 —— 把现象描述清楚，剩下的交给开发者。

### 2. 校对汉化、报告日文残留

游戏文字量巨大，难免有遗漏或错译：

- 玩的时候留意 **还是日文** 或 **翻译别扭** 的地方；
- 截图标出位置，附上 **日文原文**（如果看得到）和 **你建议的译法**；
- 提交到 Issue，或者直接参与汉化（见 [Lv.2](/contributing/client/intermediate)）。

::: tip 汉化校对的小窍门
- 注意 **语气**：魔纪角色性格各异，台词翻译要贴合人设；
- 注意 **术语统一**：同一个词（如"魔法少女""记忆结晶"）全游戏应一致；
- 注意 **长度**：UI 框是固定的，译文太长会溢出或被截断。
:::

### 3. 测试新版本

每次发布预发布（internal-test）版本时：

- 帮忙安装、试玩，确认核心流程（下载资源→登录→进游戏→存档）正常；
- 把发现的回归问题反馈出来；
- 这能帮助新版本更快稳定。

### 4. 完善文档与 FAQ

- 你踩过的坑、解决的问题，很可能别人也会遇到；
- 在 [FAQ](/player/faq) 发现缺失或过时的内容 → 提 Issue 建议补充，或直接编辑（每页底部有"在 GitHub 上编辑此页"）；
- 帮新手把"我当初卡在哪"写成清晰的步骤，价值很大。

### 5. 答疑与社区互助

- 在 Issue 区看到你知道答案的问题 → 友善地帮忙解答；
- 把常见问题的解法沉淀进 FAQ。

## 怎样提一个 Issue（手把手）

1. 注册一个 [GitHub](https://github.com) 账号（免费）；
2. 打开 [项目 Issues 页](https://github.com/MagirecoCN-Revival-Project/magireco-cnv-client/issues)；
3. **先搜索** 有没有相同问题；
4. 没有就点 **New Issue**，按 [反馈指南](/player/feedback) 的要点填写；
5. 提交后留意通知，开发者可能会追问细节。

## 怎样直接编辑文档（进阶一点点）

不想走完整的 Git 流程也能改文档：

1. 在任意文档页底部点 **"在 GitHub 上编辑此页"**；
2. GitHub 会引导你 **Fork**（复制一份）并在线编辑；
3. 改完点 **Propose changes** → **Create pull request**；
4. 维护者会 review 并合并。

整个过程在浏览器里完成，不需要装任何工具。这其实已经是一次标准的代码贡献了！

## 成长路径

当你做了一阵子，想更进一步：

- 想 **亲手改汉化文件** → 进入 [Lv.2 进阶贡献者](/contributing/client/intermediate)；
- 先把 [协作流程](/contributing/client/workflow) 读熟，它对所有级别通用。
