# 贡献者总览

魔法纪录 CNV 是一个 **社区驱动** 的复刻项目，需要各种各样的人参与 —— 不只是程序员。这一章按 **技术深度分成三级**，帮你找到适合自己的切入点。

## 三级贡献者

<div class="vp-doc">

| 级别 | 你是谁 | 你能做什么 | 需要的技能 |
|---|---|---|---|
| **[Lv.1 零基础](/contributing/client/beginner)** | 玩家、爱好者 | 反馈 bug、校对汉化、整理 FAQ、补充文档、测试新版本 | 会玩游戏、会用 GitHub 提 Issue |
| **[Lv.2 进阶](/contributing/client/intermediate)** | 会改文件、懂一点工具 | 改图集/UI JSON 汉化、扩充 `cnv_shadow.js` 字典、本地构建验证、写文档 | 文本编辑、JSON、基本 Git、图像处理 |
| **[Lv.3 资深](/contributing/client/advanced)** | 开发者、逆向工程师 | 改 Java 业务逻辑、smali 注入、native hook、协议设计、构建系统 | Android/Java、C++、apktool/smali、逆向 |

</div>

## 我该从哪一级开始？

```
只想帮忙但不懂技术    →  Lv.1：从反馈和汉化校对开始，零门槛
会改文件、想动手汉化  →  Lv.2：改资源文件和字典，本地验证
是开发者、想改核心    →  Lv.3：先通读技术文档，再认领模块
```

::: tip 级别不是门槛，是路径
你不必"够格"才能贡献。**任何级别的参与都有价值**，而且可以逐级成长 —— 很多资深贡献者都是从提一个 Issue、改一个错别字开始的。
:::

## 通用前置

无论哪一级，开始前请：

1. **读完 [技术文档](/client/) 中与你方向相关的部分** —— 至少读 [三层架构总览](/client/architecture)；
2. **了解 [协作流程](/contributing/client/workflow)** —— 分支、提交信息、PR 规范；
3. **认同项目定位** —— 仅供学习研究、非商业、尊重原版权方（见 [版权](/about/license)）。

## 项目价值观

- **态度体现在细节**：连调试信息、测试文件里的日文也要汉化 —— 我们认真对待每一处文字；
- **安全优先**：任何涉及账号、存档、校验的改动都要格外谨慎，宁可保守拦截也不 fail-open；
- **不破坏可重复构建**：改动要能通过 CI 全自动出包；
- **尊重玩家**：清晰的提示、友好的错误信息、不丢存档。
