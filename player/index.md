# 玩家指南 · 从这里开始

欢迎来到 **魔法纪录 CNV 客户端** 玩家指南。这一章写给只想把游戏跑起来的你 —— **全程不需要任何技术背景**。

## 这是什么？

魔法纪录（マギアレコード）日服与国服都已先后停止运营。本项目是一个 **民间复刻计划** 的客户端：

- 以 **Totentanz 客户端**（日服原版客户端的二开）为基础，改造成可以连接到 **复刻服务器**（游戏后端为 Totentanz）的中文版本；
- 内置 **多层汉化**，覆盖菜单、商店、扭蛋、剧情、战斗台词等绝大部分文字；
- 支持 **在线下载** 或 **离线包注入** 两种方式准备游戏资源；
- 支持 **账号登录** 与 **云端存档同步**，换设备也能继续玩。

::: tip 一句话总结
下载我们的 APK → 安装 → 准备游戏资源 → 登录账号 → 开始游戏。
:::

## 我需要准备什么？

| 项目 | 要求 |
|---|---|
| 设备 | Android 5.0 及以上的手机 / 平板（暂不支持 iOS） |
| 存储空间 | 建议预留 **15 GB 以上**（完整游戏资源较大） |
| 网络 | 在线下载需要能访问资源镜像；也可用离线包 |
| 账号 | 在登录界面可现场注册，无需提前准备 |
