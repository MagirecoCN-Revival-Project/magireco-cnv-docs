魔法纪录是一个资源量很大的游戏（图集、语音、剧情、动画等），完整资源可达 **十几 GB**。客户端提供两种准备资源的方式，引导程序会在首次启动、资源未就绪时让你选择。

## 两种方式怎么选？

| | 在线下载 | 离线包注入 |
|---|---|---|
| 适合 | 网络通畅、不想找文件的玩家 | 已经拿到官方离线 zip、或网络不稳的玩家 |
| 来源 | 多个 CDN 镜像并发下载 | 你本地的离线包文件 |
| 优点 | 全自动、断点续传、自动校验 | 不依赖在线带宽，可离线传包 |
| 注意 | 需较好网络，耗流量 | 需自行获取正确的离线包 |

::: tip 推荐
网络条件允许的话，**优先用在线下载** —— 它会自动多镜像并发、断点续传，并对每个文件做完整性校验，最省心。
:::

## 方式一：在线下载

1. 在"选择资源准备方式"对话框选择 **在线下载**。
2. 如果服务器提供了多条 **线路**，会让你选一条（通常选默认即可，网络不好时可换其他线路）。
3. 选择 **并发数**（同时下载几个文件，默认即可；网络差时调小）。
4. 等待下载。界面会显示总进度和每个文件的进度条。

下载特性：

- **断点续传**：中途断网或退出，下次会从断点继续，不用从头再来。
- **自动校验**：每个文件下载后会做 SHA-256 校验，损坏会自动重下。
- **自动换线**：某个镜像变慢或失败时，服务器可指挥客户端自动切换到更快的镜像。

下载完成后会写入"资源就绪"标记，之后启动就会直接进游戏，不再重复下载。

## 方式二：离线包注入

如果你已经有官方提供的离线资源 zip 包：

1. 在"选择资源准备方式"对话框选择 **离线包注入**。
2. 在来源对话框确认后，会弹出 **系统文件选择器**，找到并选中你的离线包 `.zip`。
3. 客户端会：
   - 把文件复制到私有目录（防止中途被篡改）；
   - 校验 zip 格式；
   - **向服务器实时获取最新的 SHA-256 指纹并比对**；
   - 两阶段解压到游戏目录。

### 关于完整性校验

为保护你的设备和账号，离线包注入有严格校验：

- 客户端会在你 **选定文件之后**，再向服务器请求 **最新** 的文件指纹（SHA-256）。
- 如果你的离线包和服务器记录 **不一致**，会提示：

  > 离线包文件与服务端记录不符，请重新下载最新版离线包后重试。

  此时注入会被拒绝，**无法跳过**。请确保你的离线包来自官方且是最新版。

### 离线包版本过低

每次启动时，客户端会检查你已安装的离线包版本是否满足服务器要求的最低版本。如果太旧，会弹窗让你选择：

- **在线下载** —— 改用在线方式重新获取最新资源；
- **重新注入** —— 选择一个更新的离线包重新注入；
- **暂时忽略** —— 继续用旧资源（可能导致游戏内容缺失或异常，不推荐）。

## 应急：临时离线注入

当 **服务器暂时连不上、你又还没下载过资源** 时，客户端允许一次"临时离线注入"应急进入游戏：

- 它 **只做离线包内部的本地校验**（zip 格式 + 解压逐条 CRC），不联系服务器；
- 进入游戏后，屏幕角落会显示红色提示 **"临时离线注入，未经过校验，请仔细核对游戏内容"**；
- 这种资源 **不算正式安装**：服务器恢复后，客户端会清除它并要求你重新正式下载或注入。

## 常见情况

- **进度条卡住不动？** 先看 [FAQ](/player/faq#资源下载卡住或失败) 的排查步骤。
- **下载很慢？** 尝试换一条线路、或减小并发数后重试。
- **反复要求重新下载？** 可能是文件损坏或离线包版本过低，按上面的提示处理。
