# 常见问题解答 (FAQ)

按问题类型分组。找不到答案时，请看 [向开发者反馈问题](/player/feedback)。

## 安装相关

### 安装时提示"应用未安装"或被拦截

多为手机厂商的侧载拦截。请到 **设置 → 安全 / 应用管理** 中允许浏览器或文件管理器"安装未知来源应用"，再重试。详见 [安装页](/player/install#安装被拦截-提示应用有害怎么办)。

### 提示"客户端完整性校验失败"

客户端启动时会检测自身是否被二次打包/篡改。出现此提示说明：

- 你安装的 **不是官方原版** APK（可能被第三方修改过），或
- 安装包在传输中损坏。

**请从 [官方 Releases](https://github.com/MagirecoCN-Revival-Project/magireco-cnv-client/releases) 重新下载安装。** 不要使用任何来源不明的"修改版/破解版"。

### 提示"客户端需要更新"

你的版本已不被服务器支持。按弹窗提示进行 **应用内更新**，或手动到 Releases 下载最新版覆盖安装。

## 资源下载相关

### 资源下载卡住或失败

依次尝试：

1. **检查网络**，切换 Wi-Fi / 移动数据后重试；
2. 重启客户端 —— 下载支持 **断点续传**，会从断点继续，不会白下；
3. 在下载前的选项里 **更换线路** 或 **减小并发数**；
4. 仍不行可改用 [离线包注入](/player/resources#方式二离线包注入)。

### 反复提示"请重新下载最新版离线包"

你的离线包与服务器记录的指纹不一致，可能是：包不是最新版、来源不对、或文件损坏。请获取 **官方最新离线包** 后重试，或改用在线下载。

### 提示"离线包版本过低"

服务器要求更高版本的资源包。按提示选择 **在线下载** 或 **重新注入** 更新的离线包。选"暂时忽略"可能导致游戏内容缺失。

### 每次启动都要重新下载

正常情况下载完成后会写"就绪"标记，不应重复下载。如果反复要求下载，可能是：

- 上次是 **临时离线注入**（应急资源不算正式安装，服务器恢复后需正式安装）；
- 资源完整性校验未通过被要求重下；
- 触发了 **崩溃恢复**（见下）。

## 启动与运行相关

### 游戏频繁闪退 / 启动异常

如果游戏在启动后很快崩溃，连续几次后客户端会弹出 **"检测到游戏启动异常"**，提供：

- **重新注入资源**（推荐，可修复损坏的资源）；
- **继续启动**（忽略提示再试一次）；
- **查看日志**。

如果重装资源仍频繁闪退，请 [反馈给开发者](/player/feedback) 并附上设备型号和系统版本。

### 卡在粉色启动界面

粉色界面是我们的引导程序。卡住通常是 **网络握手** 或 **资源校验** 慢，请耐心等待；长时间不动则检查网络后重启。点击界面左上角的 **LOG 胶囊** 可以查看详细日志，有助于定位问题。

### 进游戏后某些文字还是日文

本项目的汉化在持续完善中。绝大部分菜单、商店、扭蛋、剧情已汉化，但可能仍有少量遗漏。欢迎把遗漏的位置 [反馈](/player/feedback) 给我们，或直接 [参与汉化贡献](/contributing/client/beginner)。

## 账号与存档相关

### 登录验证码一直过不去

验证码在后台自动计算，依赖网络。请确保网络通畅后重试；多次失败可重启客户端。

### 存档没了 / 进度回退

- 先确认你登录的是 **同一个账号**；
- 进游戏前的存档检查中，如果选错了方向（用空存档覆盖了云端），可能造成回退；
- 若仍异常，请尽快 [反馈](/player/feedback)，**不要继续游戏覆盖存档**。

### 提示"账号已被封禁"

弹窗会显示封禁原因和解封时间。如有异议请通过 [反馈渠道](/player/feedback) 联系管理员。

### 提示"服务器维护中"

服务器正在维护，弹窗会显示预计完成时间，请稍后再试。

## 其他

### 悬浮存档按钮不见了

需要 **悬浮窗权限**。请到 **设置 → 应用 → 魔法纪录 CNV → 权限 → 显示在其他应用上层** 中开启，然后重启游戏。

### 这个客户端收费吗 / 内购是真的吗？

本项目 **完全免费、仅供学习研究**。游戏内的"宝石/付费"等是原版界面残留，**不涉及真实付费**。任何向你收费的行为都与本项目无关，请勿上当。
