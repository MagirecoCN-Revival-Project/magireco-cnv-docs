# 下载与安装游戏

本页教你从零拿到一个可运行的客户端。

## 第一步：下载 APK

客户端通过 GitHub 自动发布，每个版本都是一个 `.apk` 安装包。

前往 **[GitHub Releases 页面](https://github.com/MagirecoCN-Revival-Project/magireco-cnv-client/releases)** 下载最新版本：

- 文件名形如 `magireco-cn-v4.0.1.apk`；
- 选择标记为 **最新（Latest）** 的正式版本即可；
- 标记为 **预发布（Pre-release）** 的是内测版本，可能不稳定，普通玩家不建议使用。

::: tip 两种发布渠道
本项目有两个构建渠道，区别只在于"应用内更新"时去哪里取新版本：

- **正常版（normal）**：面向普通玩家的稳定发布。
- **内测版（internal-test）**：每次代码推送自动构建，更新更频繁但可能有 bug。

普通玩家请始终选 **正常版 / Latest**。
:::

## 第二步：安装 APK

1. 用手机的浏览器或文件管理器打开下载好的 `.apk` 文件。
2. 系统可能提示 **"出于安全考虑，您的手机禁止安装来源不明的应用"** —— 这是 Android 对所有非应用商店安装包的统一提示，按提示进入设置，**允许该来源安装** 即可。
3. 点击"安装"，等待完成。

### 安装被拦截 / 提示"应用有害"怎么办？

部分手机厂商（如小米、华为、OPPO、vivo）的系统会对侧载应用做额外拦截或"安全扫描"：

- 出现 **"安装包可能存在风险"** 之类提示时，选择 **"继续安装"** 或 **"仍然安装"**；
- 部分系统需要先在 **设置 → 安全 → 未知来源应用安装** 中为你的浏览器/文件管理器开启权限；
- 若提示需要登录厂商账号才能安装，可在该提示页找到"忽略风险继续安装"的小字入口。

::: warning 关于"病毒"误报
本客户端会做网络请求、文件读写和悬浮窗显示，这些行为有时会被安全软件误判。本项目源码完全公开、构建过程在 GitHub Actions 上全程可查。如不放心，可自行从源码构建（见 [构建系统](/client/build)）。
:::

## 第三步：首次启动与授权

第一次打开客户端时：

1. 会看到一个 **粉色的启动引导界面**（带进度条和贡献者署名），这是我们自己的引导程序，不是游戏本体。
2. 客户端会请求 **悬浮窗权限（在其他应用上层显示）** —— 这是 **存档悬浮按钮** 所需，请允许。没有它你将无法在游戏中手动存档。
3. 引导程序会依次完成：完整性校验 → 与服务器握手 → 检查游戏资源是否就绪。

如果这是全新安装、还没有游戏资源，引导程序会带你进入 **资源准备流程** —— 请继续阅读 **[下载游戏资源文件](/player/resources)**。

## 升级到新版本

- 客户端在启动握手时会检查版本。如果你的版本太旧、服务器不再支持，会弹窗提示 **应用内更新**，按提示下载安装新 APK 即可。
- 你也可以随时手动到 Releases 页面下载新版本覆盖安装；**已下载的游戏资源和本地存档不会丢失**。

## 卸载与重装

- 卸载客户端会清除应用数据（含已下载的游戏资源）。
- 但只要你 **登录过账号并同步过存档**，重装后重新登录即可从云端恢复进度，详见 [账号与存档](/player/account)。
