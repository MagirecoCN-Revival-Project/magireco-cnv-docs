# 向开发者反馈问题

遇到 bug、汉化遗漏或有建议？这一页教你怎样反馈，**让开发者能最快帮到你**。

## 反馈渠道

主要渠道是 **GitHub Issues**：

👉 **[提交 / 查看问题](https://github.com/MagirecoCN-Revival-Project/magireco-cnv-client/issues)**

1. 先 **搜索** 一下，看是否已有人反馈相同问题 —— 如果有，给它点个 👍 或补充你的情况即可，不必重复开。
2. 没有的话，点击 **New Issue** 新建。

::: tip 不会用 GitHub？
GitHub 账号免费注册。如果你实在不便使用，也可以通过项目主页公布的其他社区渠道反馈，但 GitHub Issues 是最不容易遗漏的。
:::

## 一份好的反馈包含什么？

把下面这些信息写清楚，能极大提高问题被解决的速度：

### 1. 环境信息

- **客户端版本**：在启动界面或 Releases 页面能看到，形如 `v4.0.1`；
- **设备型号**：如 `小米 13` / `三星 S23`；
- **系统版本**：如 `Android 14`；
- **资源准备方式**：在线下载 还是 离线包注入。

### 2. 问题描述

- **你做了什么**（操作步骤，越具体越好）；
- **期望发生什么**；
- **实际发生了什么**。

> 反例："游戏坏了。"
> 正例："在商店点击'十连召唤'后，界面卡住约 3 秒然后闪退回桌面，每次都能复现。"

### 3. 证据材料

- **截图 / 录屏**：最直观，强烈推荐；
- **日志**：粉色启动界面左上角有 **LOG 胶囊**，点开可查看详细日志，把相关部分截图或复制下来；
- **闪退时间点**：大致是"启动时 / 下载时 / 进游戏后 / 某个具体操作时"。

## 不同类型问题的反馈要点

| 问题类型 | 额外需要提供 |
|---|---|
| **闪退 / 崩溃** | 复现步骤、崩溃发生的阶段、启动日志截图 |
| **资源下载失败** | 用的哪条线路、并发数、卡在哪个文件、错误提示原文 |
| **汉化遗漏 / 错译** | 出现位置的截图、日文原文、建议译法（见下） |
| **存档 / 账号问题** | **先停止游戏不要继续覆盖存档**，说明账号是否一致、何时开始异常 |
| **画面 / 显示异常** | 截图、设备分辨率、是否横竖屏切换时出现 |

## 汉化问题特别说明

如果你发现 **某处文字没汉化或翻译不准**：

- 截图标出位置；
- 如果能看到 **日文原文**，一并写上；
- 有更好的译法欢迎直接建议。

汉化是社区驱动的工作，你的反馈会直接帮助改进。如果你愿意更进一步，可以直接参与 —— 见 [零基础贡献者指南](/contributing/client/beginner)。

## 安全相关问题

如果你发现的是 **安全漏洞**（例如可能泄露账号、绕过校验等），请 **不要公开发 Issue**，而是通过项目主页的私密渠道联系维护者，给我们时间修复后再公开，保护其他玩家。

## 反馈之后

- 开发者会在 Issue 下回复，可能会 **追问更多细节**，请留意通知；
- 问题修复后通常会在新版本中发布，记得更新客户端；
- 感谢你的耐心 —— 清晰的反馈是项目变好的最大动力 ❤️
