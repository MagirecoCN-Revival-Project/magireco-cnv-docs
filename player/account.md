# 账号、存档与离线模式

## 注册与登录

资源准备好后，进入游戏前会显示 **登录界面**：

- **没有账号？** 在登录界面即可现场 **注册**，按提示填写用户名和密码。
- **忘记密码？** 点击对应入口会打开找回页面。
- **记住登录**：默认开启。开启后下次启动会用服务器签发的 **会话令牌** 自动恢复登录，不必每次输密码。

::: tip 关于安全
客户端 **不会在本地保存你的明文密码**。"记住登录"保存的是服务器签发的、可被服务器随时撤销的会话令牌，比保存密码更安全。
:::

### 登录时的人机验证

登录可能需要完成一次 **人机验证（验证码）**。客户端会在后台一个隐藏页面里自动完成计算型验证（无需你手动点图），稍等片刻即可。如果长时间卡在验证，请检查网络后重试（见 [FAQ](/player/faq#登录验证码一直过不去)）。

## 云端存档同步

本客户端支持 **云存档**，核心机制如下：

### 进游戏前的存档检查

每次登录后、进入游戏前，客户端会比较 **本地存档** 与 **云端存档**：

| 情况 | 客户端行为 |
|---|---|
| 本地与云端一致 | 直接进入游戏 |
| 只有云端有存档 | 提示是否 **下载云端存档** 到本地 |
| 只有本地有存档 | 静默上传到云端 |
| 两边都有但不同 | 弹出 **存档冲突** 对话框，由你选择保留哪一份 |

### 游戏中的自动存档

进入游戏后，屏幕上会出现一个 **粉色的悬浮存档按钮**（软盘图标 + 进度环）：

- **自动存档**：每 **10 分钟** 自动把进度同步到云端，按钮上的进度环表示距下次自动存档的时间。
- **手动存档**：**点击** 悬浮按钮即可立即存档。
- **移动按钮**：**拖动** 按钮可以把它挪到不挡视线的位置，位置会被记住。

::: warning 请正常退出
重要进度后建议点一下悬浮按钮手动存档。虽然有自动存档，但如果在两次自动存档之间强制杀掉应用，最近的进度可能来不及上传。
:::

存档同步有 **频率限制**（约每分钟最多 2 次上传），短时间内频繁手动存档会被提示稍后再试，属正常保护机制。

## 离线模式

当客户端 **连续多次连不上服务器** 时，会询问你怎么办：

### 资源已就绪时

弹出三个选项：

- **重试** —— 再次尝试连接服务器；
- **离线模式** —— 直接进入游戏（连接私服后端运行），但 **账号登录和存档同步不可用**；
- **退出**。

进入离线模式后，屏幕角落会显示 **"离线模式 v版本号"** 标签。

### 资源还没下载时

会让你选择：重试、**用本地离线包临时注入** 应急进入、或退出。临时注入的资源不算正式安装（见 [资源下载页](/player/resources#应急临时离线注入)）。

## 封禁与维护提示

- 如果你的账号被服务器封禁，客户端会在启动或游戏中弹窗告知 **原因** 和 **解封时间**（永久封禁会注明）。
- 服务器维护期间，会显示维护公告和 **预计完成时间**。
- 这些提示可能在游戏过程中实时出现 —— 客户端每 5 秒与服务器保持一次心跳，能即时收到封禁/维护指令。

## 换设备 / 重装后恢复进度

只要你 **登录过账号并同步过存档**：

1. 在新设备安装客户端并准备好资源；
2. 用 **同一个账号** 登录；
3. 在存档检查环节选择 **下载云端存档**，进度即可恢复。
